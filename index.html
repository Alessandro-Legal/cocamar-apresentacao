Especificação da Solução

Projeto: COCAMAR - Sistema de Pesagem Rodoviária com Automação Guardian e OCR

Local: Maringá, PR | Quantidade: 5 Balanças Rodoviárias 950i (30m × 3,2m, 120t)

Objetivo: Implementar solução completa de pesagem rodoviária com automação inteligente, OCR duplo check e integração com ERP COCAMAR via Web Service.

Análise da Especificação

A solução proposta pela Toledo do Brasil para a COCAMAR representa uma modernização completa do processo de pesagem rodoviária, integrando tecnologia de ponta em automação, reconhecimento óptico de caracteres (OCR) e gerenciamento inteligente através do software Guardian. O projeto foi desenvolvido em 9 revisões, incorporando feedback operacional específico da COCAMAR.

Potencialização do Processo

  • Automação completa do fluxo de pesagem (entrada, identificação, posicionamento, pesagem, liberação)
  • Duplo check de identificação (RFID + OCR + Radar) para máxima segurança
  • Integração com ERP COCAMAR via Web Service SOAP/REST
  • Monitoramento em tempo real através do Cloud Prix Guardian
  • Redução de fraudes e erros operacionais
  • Otimização do fluxo de pátio com YMS (Yard Management System)
  • Rastreabilidade completa de todas as operações

Funcionamento da Automação Guardian

Fluxo Operacional Completo

Etapa 1 - Identificação: Antena UHF lê TAG do veículo na entrada. Sistema consulta ERP COCAMAR para validar agendamento.

Etapa 2 - Posicionamento: Sensores transversais garantem posicionamento correto sobre a balança. Semáforo orienta motorista.

Etapa 3 - Pesagem: Balança 950i realiza pesagem com células digitais inteligentes. Display mostra resultado.

Etapa 4 - OCR Duplo Check: Câmera OCR captura placa do veículo para validação cruzada com RFID.

Etapa 5 - Liberação: Sistema autoriza saída através de cancela e semáforo. Ticket é impresso (opcional).

Etapa 6 - Integração: Dados de pesagem + OCR + RFID + Radar são enviados ao ERP COCAMAR com rastreabilidade completa.

Componentes do Fluxo

  • RFID UHF para identificação automática de veículos
  • Sensores de posicionamento para garantir precisão de pesagem
  • Câmera OCR para validação visual de placa
  • Sensor Radar para detecção de presença e movimento
  • Cancelas automáticas para controle de acesso
  • Semáforos para orientação visual do motorista
  • Display de mensagens para comunicação com usuários
  • Integração com ERP via Web Service SOAP/REST

Sistema OCR - Duplo Check (RFID + OCR + Radar)

Conceito de Duplo Check

O sistema OCR Guardian implementa um mecanismo de duplo check para máxima segurança na identificação de veículos, combinando três tecnologias complementares: (1) RFID - Identificação por TAG; (2) OCR - Reconhecimento óptico de placa; (3) Radar - Sensor de posicionamento.

Funcionamento Técnico do OCR Duplo Check

Etapa 1: Veículo entra na portaria, antena UHF lê TAG. Sistema consulta ERP COCAMAR para validar agendamento.

Etapa 2: Câmera IP Prix OCR (GV-TBL4810) captura imagem da placa frontal com iluminação de refletor.

Etapa 3: Software Guardian processa imagem, extrai número de placa e compara com dados do RFID.

Etapa 4: Sensor Radar confirma presença e posicionamento correto do veículo sobre a balança.

Etapa 5: Se RFID, OCR e Radar concordam, sistema autoriza pesagem. Se houver discrepância, alerta é gerado.

Etapa 6: Dados de pesagem + OCR + RFID + Radar são enviados ao ERP COCAMAR com rastreabilidade completa.

Benefícios do Duplo Check OCR

  • Máxima segurança contra fraudes de identificação de veículos
  • Rastreabilidade visual completa (foto de placa capturada)
  • Validação cruzada de três tecnologias (RFID + OCR + Radar)
  • Alertas automáticos em caso de discrepâncias
  • Conformidade com Portaria INMETRO 19/2022
  • Redução de fraudes e erros operacionais

Caixa Coletora de Tags (CCT)

Descrição e Funcionalidade

A Caixa Coletora de Tags (CCT) é um dispositivo especializado para devolução automática de TAGs sem necessidade de operador. Permite que motoristas devolvam seus TAGs de forma rápida e segura no final do fluxo de pesagem.
